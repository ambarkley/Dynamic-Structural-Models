This workbook is a teaching illustration of a dynamic entry and exit game. It is not a replication of a particular empirical application.

Introduction: what changes when there are several decision makers?

The bus-engine model had one decision maker. Here, several firms choose simultaneously whether to be active. A firm's current payoff depends on how many rivals are active, and rivals' choices also determine next period's market structure. We therefore need beliefs about rivals' strategies before we can evaluate a firm's payoff or continuation value.

Once these expectations are constructed, the reference-action CCP argument and the second-stage logit are close to the single-agent methods used for the bus model.

Conditional on the simultaneous actions of its rivals, the deterministic payoff from being active is
Thus measures the effect of current competition and is an entry cost paid only by a firm that was previously inactive. The inactive payoff is normalized to zero. Private action shocks are independent Type-I extreme value, firms use symmetric stationary strategies, the discount factor and transition of are fixed, and rivals' shocks are independent conditional on the state.
We treat inactivity as terminal for the current player; a new potential entrant occupies that position next period. The equilibrium routine returns one symmetric fixed point for this calibration, although dynamic games need not have a unique equilibrium.

Generate the teaching data

The vector utilityIndex evaluates for each state and each possible number of current active rivals. The local function solve_equilibrium integrates over rivals' choices and finds a symmetric fixed point in the active-choice CCPs. Those equilibrium CCPs are then used only to simulate the panel that we will estimate below.
The data contain the action, permanent state, transitory state, and lagged activity of every firm. The burn-in observations are discarded so that the initial all-inactive market does not dominate the observed sample.

This is a reduced-form first stage: its purpose is to estimate firms' equilibrium strategies throughout the state space. mnrfit estimates on the simulated observations, and mnrval evaluates the fitted active-choice probability at every row of stateGrid. Interpreting the estimates

The estimated coefficients should be compared with the simulation values, not interpreted as an exact replication target. The negative rival coefficient captures the reduction in flow profit from additional competition, while the negative entry coefficient captures the cost paid by previously inactive firms. Sampling variation is visible because the lighter teaching design uses 1,000 markets.
The calculation also clarifies what is specific to a game. In the bus model the transition law was supplied directly. Here, part of the transition law is generated by other agents' estimated strategies: pActiveHat produces rivalProb, which produces both expected competition in Z and the market-structure component of FV.

Appendix: equilibrium and simulation functions

The functions below create the simulated data. They use the same two-binomial rival distribution as the estimator, but students do not need to modify them to follow the empirical steps above.
function p = solve_equilibrium(utilityIndex,trans,N,S,choose,beta,stateGrid)
gamma = double(eulergamma);
p = 1./(1+exp(-utilityIndex));
 
for iter = 1:10000
pOld = p;
for j = 1:size(stateGrid,1)
nIncumbent = stateGrid(j,1);
ownLagged = stateGrid(j,4);
[~,entryState] = ismember([min(nIncumbent+ownLagged,N), ...
stateGrid(j,2:3),0],stateGrid,'rows');
[~,incumbentState] = ismember([max(nIncumbent+ownLagged-1,0), ...
stateGrid(j,2:3),1],stateGrid,'rows');
 
rivalProb = rival_count_distribution(p(entryState),p(incumbentState), ...
N-nIncumbent,nIncumbent,choose,N);
sameState = ismember(stateGrid,[(0:N)',repmat( ...
stateGrid(j,2:4),[N+1,1])],'rows');
expectedFlow = rivalProb*utilityIndex(sameState);
 
expectedLogPInactive = 0;
for sNext = 0:S-1
nextStates = ismember(stateGrid,[(0:N)',repmat( ...
[stateGrid(j,2),sNext,1],[N+1,1])],'rows');
expectedLogPInactive = expectedLogPInactive ...
+trans(stateGrid(j,3)+1,sNext+1)*rivalProb ...
*log(1-p(nextStates));
end
index = expectedFlow+beta*(gamma-expectedLogPInactive);
p(j) = 1/(1+exp(-index));
end
if max(abs(p-pOld)) < 1e-10
return
end
end
error('Equilibrium iteration did not converge')
end
 
function prob = rival_count_distribution(pEntry,pIncumbent, ...
nEntry,nIncumbent,choose,N)
entryProb = choose(nEntry+1,1:nEntry+1) ...
.*pEntry.^(0:nEntry).*(1-pEntry).^(nEntry-(0:nEntry));
incumbentProb = choose(nIncumbent+1,1:nIncumbent+1) ...
.*pIncumbent.^(0:nIncumbent) ...
.*(1-pIncumbent).^(nIncumbent-(0:nIncumbent));
prob = conv(entryProb,incumbentProb);
prob(end+1:N+1) = 0;
end
 
function [active,x,state,lagActive] = simulate_game( ...
pActive,cdfTrans,S,Xn,I,Nm,T,burnIn,stateGrid)
active = zeros(Nm,T+burnIn,I);
lagActive = zeros(Nm,T+burnIn+1,I);
x = randi(Xn,Nm,1)-1;
state = zeros(Nm,T+burnIn+1);
state(:,1) = randi(S,Nm,1);
actionDraw = rand(Nm,T+burnIn,I);
stateDraw = rand(Nm,T+burnIn);
 
for m = 1:Nm
nActive = 0;
for t = 1:T+burnIn
for i = 1:I
[~,stateIndex] = ismember([nActive-lagActive(m,t,i), ...
x(m),state(m,t)-1,lagActive(m,t,i)],stateGrid,'rows');
active(m,t,i) = pActive(stateIndex)>actionDraw(m,t,i);
end
nActive = sum(active(m,t,:));
lagActive(m,t+1,:) = active(m,t,:);
state(m,t+1) = 1+sum(stateDraw(m,t)> ...
cdfTrans(state(m,t),1:S-1));
end
end
 
active = active(:,burnIn+1:T+burnIn,:);
state = state(:,burnIn+1:T+burnIn)-1;
lagActive = lagActive(:,burnIn+1:T+burnIn,:);
end
