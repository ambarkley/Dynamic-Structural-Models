# FGV EESP 2026 public materials

This folder is the publication copy for the Econometric Society Masterclass at
FGV EESP. The working and testing copy remains outside the Git repository in
`Brazil_2026`.

The folder structure is intentional: MATLAB files locate data using the
relative path `../Data`, so participants should preserve the `MATLAB` and
`Data` sibling folders when downloading files.

Only approved materials should be copied here. Unreleased practicum files must
not be committed to any branch of the public repository.
